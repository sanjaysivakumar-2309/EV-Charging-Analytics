# EV Charging Analytics Dashboard

## Project Overview
An interactive EV Charging Analytics project built using **Microsoft Excel and Power BI** to explore electric vehicle charging sessions, energy consumption, charging costs, station performance, and customer charging behavior.

The dashboard transforms raw charging-session data into meaningful insights through interactive visualizations, KPI cards, and slicers.

## Business Objectives
- Analyze charging-session activity across different stations.
- Monitor energy consumption and charging costs.
- Compare station-level performance.
- Understand charging patterns by hour and time of day.
- Explore payment preferences and subscription plans.
- Analyze renewable energy usage and charging status.

## Tools & Technologies
- Microsoft Excel — Data preparation and calculated columns
- Microsoft Power BI — Data modeling, DAX calculations, interactive dashboards, and visualization

## Dashboard Pages
1. **EV Overview** — Key performance indicators, charging-period analysis, hourly energy consumption, and activity heatmap.
2. **Station Intelligence** — Station-level session volumes, energy consumption, average energy per session, charging costs, and performance scorecard.
3. **Charging Behavior & Energy Insights** — Energy categories, payment preferences, subscription plans, renewable energy usage, and charging status.

## Key Performance Indicators
- Total Charging Sessions
- Total Energy Consumed
- Total Charging Cost
- Average Charging Cost
- Average Energy Consumed

## Key Features
- Three-page interactive dashboard
- Station and charger-type slicers
- Hourly and time-of-day analysis
- Station performance comparison
- Customer charging behavior analysis
- Dark-themed dashboard with consistent visual design

## Files Included
- Power BI dashboard (`.pbix`)
- Excel workbook (`.xlsx`)
- Dashboard screenshots

## Project Purpose
This project demonstrates practical skills in data preparation, business intelligence, interactive dashboard design, and analytical storytelling for EV charging operations.
